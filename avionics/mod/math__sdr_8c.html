◆ math_quat_normalize()

QUAT math_quat_normalize ( QUAT q)

Normalizes a quaternion to unit length.

Parameters
qThe quaternion to normalize.
Returns
The normalized unit quaternion.

Divides each component by the quaternion's norm. If the norm is zero (e.g. a zero-initialized quaternion), returns the identity quaternion (1, 0, 0, 0) to avoid a divide-by-zero. Values near but not equal to zero are divided normally and may exhibit floating-point roundoff.

QUAT vector_body )

Rotates a vector from the body frame into the world frame.

The attitude quaternion represents the body-to-world rotation: 

vector_world = q * vector_body * conjugate(q)
